# 노션 화면 실측 — 디자인 트랙의 기준값

**잰 날:** 2026-10-25
**잰 곳:** 노션 공식 템플릿 계정의 공개 페이지(`notion-templates.notion.site`). 로그인 없이 노션 편집기와 같은 렌더러로 그려진다. 창 폭 1440 · 밝은 테마 기본. 어두운 테마는 `prefers-color-scheme: dark` 에뮬레이션으로 쟀다.

- 위키 첫 화면 — https://notion-templates.notion.site/de1cdbdd9c774f088211007a2b3401c3 (넓은 레이아웃)
- 보통 폭 페이지 — https://notion-templates.notion.site/Getting-Started-ade01a27e80a418ba830b76580f48c42
- 제목3 · 코드 — https://notion-templates.notion.site/Code-Reviews-47dabe7212594636be46a2838aaeb882

값은 브라우저가 계산한 스타일(`getComputedStyle`)과 상자 크기(`getBoundingClientRect`)를 그대로 옮겼다. 노션이 바꾸면 다시 잰다 — 이 문서가 그 날짜의 기준이다.

## 따라하는 것과 따라하지 않는 것

**따라한다:** 배치 · 간격 · 글자 크기와 굵기 · 색 · 둥글기 · 그림자 같은 시각 규칙. 글꼴은 노션과 같은 **시스템 글꼴 묶음**이다(운영체제에 이미 있는 글꼴 — 내려받지 않고 사용권 문제도 없다).

**따라하지 않는다:** 노션의 로고 · 이름 · 일러스트 · 자체 아이콘 그림 · 자체 글꼴 파일. 아이콘이 필요하면 무료 라이선스 아이콘(예: Lucide — ISC)을 쓴다. 화면에 노션이라는 이름을 쓰지 않는다.

## 글꼴

| 쓰임 | 값 |
|---|---|
| 본문 · 화면 | `ui-sans-serif, -apple-system, BlinkMacSystemFont, "Segoe UI Variable Display", "Segoe UI", Helvetica, "Apple Color Emoji", Arial, sans-serif, "Segoe UI Emoji", "Segoe UI Symbol"` |
| 코드 | `SFMono-Regular, Menlo, Consolas, "PT Mono", "Liberation Mono", Courier, monospace` |

한글은 묶음의 글꼴에 없으므로 브라우저가 운영체제의 한글 글꼴(Windows 맑은 고딕 · macOS Apple SD 산돌고딕 Neo)로 넘긴다 — 노션도 같다.

## 색 (밝은 테마)

| 쓰임 | 값 |
|---|---|
| 글자(기본) | `rgb(44, 44, 43)` |
| 글자(흐린 — 목차 · 속성 이름 · 보조) | `rgb(125, 122, 117)` |
| 페이지 배경 | `rgb(255, 255, 255)` |
| 구분선 | `rgba(28, 19, 1, 0.11)` (1px) |
| 콜아웃 파랑 배경 | `rgb(229, 242, 252)` |
| 코드 블록 배경 | `rgba(66, 35, 3, 0.03)` |
| 갈색 태그 | 글자 `rgb(88, 68, 55)` · 배경 `rgba(127, 51, 0, 0.157)` |

어두운 테마(일부): 제목 글자 `rgb(240, 239, 237)` · 콜아웃(기본 회색) 배경 `rgb(56, 56, 54)`. 나머지는 어두운 테마 조각에서 잰다.

## 블록 — 크기와 간격

노션의 블록은 감싸개(`padding`)와 글자 칸(`padding: 2px`) 두 겹이다. 이웃한 블록 사이에 바깥 여백(`margin`)은 없다 — 간격은 모두 안쪽 여백이다.

| 블록 | 글자 | 감싸개 안쪽 여백(위/오른쪽/아래/왼쪽) | 한 줄일 때 블록 높이 |
|---|---|---|---|
| 문단 | 16px · 400 · 24px | 6 / 6 / 6 / 6 | 40px |
| 제목1 | 30px · 600 · 39px(1.3) | **30** / 6 / 6 / 6 | 79px |
| 제목2 | 24px · 600 · 31.2px(1.3) | **26** / 6 / 6 / 6 | 67px |
| 제목3 | 20px · 600 · 26px(1.3) | **22** / 6 / 6 / 6 | 58px |
| 글머리 목록 | 16px · 24px | 6 / 6 / **1** / 6 · 기호 칸 폭 24px | 35px |
| 콜아웃 | 16px · 24px | 감싸개 8px · 상자 안쪽 12px · 둥글기 **10px** · 아이콘 약 17px | — |
| 코드 | 13.6px(0.85em) · 20.4px(1.5) · 코드 글꼴 | 감싸개 8px · 상자 둥글기 **10px** · 상자 안쪽 24px/22px | — |
| 목차 | 14px · 흐린 글자 · 밑줄 | 감싸개 8px | — |
| 태그(선택 값) | 14px · 20px | 높이 20px · 좌우 6px · 둥글기 4px | — |

글자 간격(`letter-spacing`)은 어디에도 없다(`normal`).

## 아직 재지 못한 것

로그인해야 보이는 앱 화면 — 사이드바 · 상단 바의 동작 단추 · 메뉴 · 팝오버 · 데이터베이스 편집 화면. 공개 페이지에는 그려지지 않는다. 해당 조각을 할 때 정한다(사용자의 로그인된 브라우저에 붙어 재거나, 공개 자료로 갈음).
